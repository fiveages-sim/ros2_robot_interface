# 搬箱参考 pose 流程测试

测试脚本：`run_box_transfer.py`。只执行机器人头、腰、双臂动作，不移动底盘、不接入视觉、不操作夹爪。
使用 2026-10-22 日志去重后的平均目标替代视觉，测试动作编排和目标到位；不等同原业务流程回放。
配置 `task_config.json` 位于脚本同目录，原日志位于工作区 `shunfeng/`；脚本内嵌平均目标，运行时只读取配置。

## 默认执行

在本目录加载 ROS 2 和工作区环境后执行：

```bash
python3 run_box_transfer.py
```

等同于：

```bash
python3 run_box_transfer.py --level all --execute --quaternion-order xyzw --body-layers 1,2,0
```

按照用户指定，默认低→中→高三轮，四元数顺序 xyzw，腰部配置映射如下：

| 档位 | G 点配置索引 | 身体关节角（度） |
|---|---|---|
| low | 1 | [-75.33, -136.69, -61.36, 0] |
| middle | 2 | [-56.88, -106.34, -49.46, 0] |
| high | 0 | [-14.78, -28.17, -13.39, 0] |

每一步回车后执行，输入 q 终止；每轮结束回 home。`--auto` 取消逐步回车。
此映射为用户指定的配置选择，不代表原日志的身体目标映射。

## 离线预览

仅预览必须加 `--dry-run`，不会导入 ROS 或连接机器人：

```bash
python3 run_box_transfer.py --dry-run
python3 run_box_transfer.py --level low --dry-run
python3 run_box_transfer.py --level middle --dry-run
python3 run_box_transfer.py --level high --dry-run
```

预览打印每一步的目标；pose 单位为米，关节目标打印为度，执行时转换为弧度。
默认读取脚本同目录的 `task_config.json`，也可用 `--config /absolute/path/task_config.json`。
默认取箱点 A、放箱点 G；可用 `--station` / `--place` 修改配置来源。
平均视觉目标仍来自整份历史日志，修改站点不会重新计算平均值。
`--body-layers` 和 `--quaternion-order` 仍可覆盖默认值。

默认运动时长 4 秒、到位超时 20 秒，位置容差 0.01 m、姿态容差 3°、关节容差 0.03 rad。
可通过 `--duration`、`--timeout`、`--position-tolerance`、`--angle-tolerance`、`--joint-tolerance` 调整。
平均 pose 尚未验证可达性或碰撞，先无箱逐步验证。

## 每轮动作

| 顺序 | 动作 | 控制/目标来源 |
|---|---|---|
| 1 | 头部观察 | 关节目标 [0, 0.26] rad |
| 2 | 全身准备 | MOVEJ，取箱点 box 中的腰部与双臂 home |
| 3 | 双臂外侧预备 | 笛卡尔平均目标；代替视觉检测 |
| 4 | 向内抓箱 | 笛卡尔平均目标；没有夹爪开合 |
| 5 | 同步抬升 | 当前反馈转换到 base_link 后，双臂 Z 各增加 0.4 m |
| 6 | 收回持箱 | 当前取箱点 back_left/right_arm_pose，按 base_link 使用 |
| 7 | 调整码放腰部 | MOVEJ，使用显式指定的目标层配置；双臂关节保持 |
| 8 | 码放预备 | 中档 half_y 平均目标；高档第三层点云平均目标 |
| 9 | 下放 | 当前高度档的平均目标 |
| 10 | 向外移开 | 当前高度档的平均目标 |
| 11 | 撤离 | 与外移目标完全相同，忠实保留日志中的零位移步骤 |
| 12 | 全身复位 | 取箱点 home |

低档没有独立可靠的码放预备目标，省略第 8 步。视觉计算和夹爪开合不属于本脚本的执行步骤。
码放腰部与准备姿态之间的转换是参考编排；原日志不提供完整、成功且逐步配对的三轮记录。
脚本不会根据 back 中命名不一致的腰部字段猜测额外持箱腰部动作。

## 数据与到位检查

| 目标 | 平均样本数 |
|---|---:|
| 外侧、抓取 | 各 84 |
| 中档码放预备 | 12 |
| 高档码放预备 | 11 |
| 低档下放、外移 | 各 49 |
| 中档下放、外移 | 各 12 |
| 高档下放、外移 | 11 / 8 |

XYZ 算术平均，四元数归一化后用主特征向量求平均，处理 q/-q 等价性。
各动作分别平均，高档下放与外移样本不同，所以均值不构成严格相同 X/Z 的撤离路径。

脚本将双臂实际反馈转换到 base_link，与本次目标直接比较位置和姿态，连续三次满足容差才继续。
关节步骤直接比较本次目标和分类关节反馈，连续三次满足容差才继续。
这些判据不检测抓箱是否牢固、箱子是否受到承托、反馈时间戳新鲜度或路径碰撞。
失败、超时、退出时尝试发送 HOLD，再断开接口；不自动回 home。HOLD 是软件请求，不替代硬件急停。
