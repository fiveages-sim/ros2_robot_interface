## IK 状态说明

| IK 状态 | 含义 |
|---|---|
| `max iterations` | DLS 已达到最大迭代次数，但最终误差仍未低于 `solutionTolerance`，因此求解失败。 |
| `best available` | BFGS 未找到满足 `solutionTolerance` 的解，只返回求解过程中误差最小的候选解；该候选解仍不满足精度要求，因此求解失败。 |
